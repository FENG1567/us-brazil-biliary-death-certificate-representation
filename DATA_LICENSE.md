# Data licensing and redistribution notice

The MIT License covers original repository code only.

The aggregate CSV files in `data/derived`, `data/source_data`, `results/reference`, `figures/reference` and `tables/source` were derived from public, de-identified or aggregate government sources for scientific reproducibility. This repository does not assert a new license over underlying government data. Users must follow the current terms, attribution requirements and access conditions of the originating agencies.

The repository intentionally excludes record-level mortality files, downloaded official documents and raw cache files. Official source URLs and versions are provided in `config/source_registry.csv` and `docs/RAW_DATA_REBUILD.md`.

Before public release, the authors should confirm with their institution or journal whether the derived aggregate CSVs may be redistributed directly. If not, retain the code and metadata but replace the affected CSV with a retrieval/rebuild instruction and checksum.
